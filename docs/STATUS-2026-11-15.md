## 3. Trial use by gyms

- **Status:** not ready yet. No gym has been chosen.
- **Before a real gym uses it, these gaps should be closed:**
  - a payment recorded by mistake cannot be cancelled;
  - every staff account has full manager powers (there is no limited front-desk role);
  - the privacy notice contains example details and has not been reviewed;
  - there are no automatic backups;
  - the app carries one gym's name and fixed prices.
- **Decision needed:** one gym first, or several. One copy per gym is quick to set up. A single system serving many gyms is a larger rebuild.

## 4. User manual and online help

- **Status:** done on the test site; **[update]** live on the main site: yes / no.
- **Manual:** 32 questions and answers for members, trainers and front-desk staff, written from the real screens.
- **Online help:** a Help page in the app with a search box. A person types a few words ("forgot password", "QR code not working") and gets the matching answers. It is reachable from every screen, before and after logging in, and costs nothing to run.
- **Chatbot:** the search is the first step. An AI assistant that answers typed questions in its own words can be added on top of the same manual. It has a small running cost per question, so it needs approval first. **Decision needed.**
- **Also fixed while writing the manual:** on a phone, members had no way to reach their profile page or sign out.
